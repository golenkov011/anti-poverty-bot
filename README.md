# Анти-бедность через решения — Telegram MVP

Первая рабочая версия системного Telegram-бота для финансовой самодиагностики.

## Что делает MVP

1. Собирает минимальный набор данных о финансовой ситуации пользователя.
2. Рассчитывает базовые показатели: баланс, долговую нагрузку, наличие просрочек, резерв.
3. Определяет 2–4 ключевые зоны риска по прозрачным правилам.
4. Выдаёт конкретный план первых действий.
5. Сохраняет только технический профиль и ответы в SQLite локально.
6. Опционально может использовать OpenAI для аккуратного пояснения результата, но диагноз и правила остаются детерминированными.

## Быстрый запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env`, укажите `BOT_TOKEN` от BotFather.

```bash
python -m app
```

Для Windows вместо `cp` можно просто скопировать `.env.example` в `.env`.

## Тесты

```bash
pytest -q
```

Тесты не требуют Telegram-токена и проверяют расчёты, правила диагностики и сценарий на типовых данных.

## Команды

- `/start` — начать
- `/help` — помощь
- `/restart` — пройти диагностику заново
- `/privacy` — информация о данных

## Архитектура

- `app/bot.py` — Telegram-слой и FSM.
- `app/diagnostic.py` — расчёты и правила.
- `app/models.py` — модели данных.
- `app/storage.py` — SQLite.
- `app/ai.py` — необязательное AI-пояснение.
- `tests/` — автоматические тесты.

## Важное ограничение MVP

Это не финансовый консультант и не кредитный брокер. Результаты являются информационной самодиагностикой. Бот не обещает экономию, одобрение кредита или рост дохода и не принимает финансовые решения за пользователя.

## Следующий этап после пилота

После первых 10–50 пользователей имеет смысл анализировать, какие вопросы непонятны, какие рекомендации реально выполняют и за какие результаты готовы платить. Не добавляйте новые функции до получения этой обратной связи.
